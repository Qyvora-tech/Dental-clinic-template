# City Smiles — Dental & Skin Clinic website

A single-page marketing site for **City Smiles Dental & Skin Clinic, Sialkot**:
dental and skin services, an interactive treatment visualiser, a before/after
comparison, a 6-step appointment booking flow that hands off to WhatsApp or a
phone call, FAQs, and a plain-English reception assistant.

Built with TanStack Start (React 19 + Vite), TypeScript, Tailwind CSS v4 and
shadcn/ui components.

## Run it locally

You need **Node.js 20 or newer** (with npm).

```sh
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:8080).

Other useful commands:

```sh
npm test           # run Vitest automated test suite
npm run build      # production build
npm run preview    # serve the production build locally
npm run lint       # ESLint
npm run format     # Prettier
```

## What lives where

| Path                    | Purpose                                                        |
| ----------------------- | -------------------------------------------------------------- |
| `src/routes/__root.tsx` | App shell: fonts, favicon, global meta tags                    |
| `src/routes/index.tsx`  | Assembles the home page sections in order                      |
| `src/components/site/`  | One file per page section (hero, booking, contact…)            |
| `src/components/ui/`    | shadcn/ui primitives                                           |
| `src/lib/clinic.ts`     | **All clinic content** — phone, hours, services, FAQs, doctors |
| `src/styles.css`        | Colours, fonts and animation utilities (Tailwind v4 theme)     |
| `src/assets/`           | Logo and photography                                           |
| `public/`               | Favicon, robots.txt                                            |

## Editing content

Most copy changes happen in **one file**: `src/lib/clinic.ts`.

- Phone / WhatsApp / map links / opening hours → `CLINIC`
- Dental services → `DENTAL_SERVICES`
- Skin services → `SKIN_SERVICES`
- Trust points, education topics, FAQs → `TRUST_POINTS`, `EDUCATION_TOPICS`, `FAQS`
- Doctor names, qualifications and bios → `DOCTORS`
- Treatment visualiser stages → `STAGE_SETS`

The doctor cards, patient stories and education videos are deliberate
placeholders until the clinic supplies real photos, reviews and footage.

## Notes

- `src/routeTree.gen.ts` is generated by TanStack Router. Don't hand-edit it —
  it rewrites itself whenever you run `npm run dev`.
- `AGENTS.md` holds build conventions for AI assistants working on the repo.
- Booking does not store data anywhere; the final step opens WhatsApp or the
  phone dialler with the details the visitor entered.
